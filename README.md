
# DG TEC — Tudo em Tecnologia

**Português | English**

## 🇧🇷 Sobre o projeto

A **DG TEC** é uma loja virtual de tecnologia desenvolvida com o objetivo de oferecer uma experiência simples e organizada para a apresentação de produtos tecnológicos.

Este projeto faz parte do meu portfólio como desenvolvedor em formação.

### Tecnologias utilizadas

- Next.js
- React
- TypeScript
- JavaScript
- CSS

### Funcionalidades e recursos

- Catálogo de produtos.
- Organização de preços e estoque.
- Configuração de modelos e ajustes dos produtos.
- Configuração de contato pelo WhatsApp.

### Como executar

1. Baixe ou clone o repositório.
2. Execute o arquivo `INICIAR.bat`.
3. Acesse no navegador: http://localhost:3000

### Configurações

- Preços, estoque e modelos: `src/data/products.ts`
- Número do WhatsApp: variável `NEXT_PUBLIC_WHATSAPP` no arquivo `.env`.

### Melhorias futuras

- Fotos reais dos produtos.
- Login de clientes.
- Painel administrativo.
- Pagamento online.
